# Novit Slide Image Catalog

This file is the index used by Novit AI to decide which images to show during a conversation.
Treat it as a brochure knowledge source: use these descriptions as grounding context when answering about Novit.
Each entry has an ID, the image URL, and a description of when to use it.

---

## portada

- **URL**: assets/images/slides/1-portada.png
- **Title**: Portada — Novit Software
- **Use when**: Al inicio de la conversación, como primer slide de presentación, o cuando el lead pide una intro general sobre Novit. Ideal si el lead dice "contame sobre Novit" o "quiero saber quiénes son". NO mostrar en el saludo automático — solo cuando el lead pida info general. **Esta imagen es TAPA DURA (cover), no página interna.**
